# MathSprint — GitHub APK Builder

This repository is configured to build the MathSprint Android app automatically on GitHub Actions.

## Build the APK from your phone

1. Upload this project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Actions**.
4. Select **Build MathSprint APK**.
5. Tap **Run workflow**.
6. Wait for the build to finish.
7. Open the completed workflow run.
8. Under **Artifacts**, download **MathSprint-debug-apk**.
9. Extract the downloaded artifact and install the APK on your Android phone.

The workflow builds a debug APK and does not require Android Studio on your phone.
