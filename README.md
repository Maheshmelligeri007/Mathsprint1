# MathSprint Android

Android Studio project packaging the supplied MathSprint PWA in a native Android WebView.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Connect an Android phone or use an emulator.
4. Run the `app` configuration.
5. For an APK: Build > Build APK(s).

The generated debug APK is normally under `app/build/outputs/apk/debug/`.
